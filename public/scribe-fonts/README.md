# Scribe product fonts (docs specimens)

These binaries are copied from the main Scribe repo:

`Scribe/packages/styles/src/fonts/`

- `tiempos-headline-web-medium.woff2`
- `charter_regular.woff2`

After updating fonts in `packages/styles`, copy the changed files here and refresh `src/scribe-product-fonts.css` if family names or weights change.

Inter for specimens is loaded from Google Fonts in `src/routes/__root.tsx`.
